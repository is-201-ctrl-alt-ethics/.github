# .github

Organization-wide defaults for **is-201-ctrl-alt-ethics**.

- `profile/README.md`: the public org profile.
- `.github/ISSUE_TEMPLATE/`: the default issue forms for every repo that has none of its own.
- `.github/pull_request_template.md`: the default PR template.

A repo that adds its own `.github/ISSUE_TEMPLATE/` or PR template overrides these.
